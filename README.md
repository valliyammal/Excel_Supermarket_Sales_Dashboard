# Supermarket Sales Dashboard

An interactive Excel dashboard for analyzing supermarket sales.

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers

## Analysis
- Category-wise Sales
- City-wise Sales
- Monthly Sales Trend
- Product-wise Sales
- Payment Mode Sales

## Key Metrics
- Total Sales: ₹1,38,750
- Total Quantity: 524
- Total Transactions: 100
- Top Product: Rice
- Top City: Chennai
